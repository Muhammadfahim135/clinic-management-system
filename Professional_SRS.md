# Software Requirements Specification (SRS)

## 1. Introduction

### Purpose

Develop a Multi-Specialty Clinic Management System.

### Scope

Manage patients, visits, appointments, prescriptions, billing, and
reports.

## 2. Stakeholders

-   Clinic Owner
-   Doctors
-   Receptionists
-   Patients

## 3. Functional Requirements

-   Authentication
-   Patient Management
-   Visit History
-   Image Upload
-   Appointments
-   Prescriptions
-   Billing
-   Dashboard & Reports

## 4. Non-Functional Requirements

-   Security
-   Performance
-   Reliability
-   Scalability
-   Usability

## 5. User Roles

-   Admin
-   Doctor
-   Receptionist

## 6. Use Cases

-   Register Patient
-   Search Patient
-   Add Visit
-   Upload Images
-   Generate Bill

## 7. Database Overview

PostgreSQL with normalized tables.

## 8. Security Requirements

JWT Authentication and Role-Based Access Control.

## 9. Testing Strategy

Unit, Integration, and User Acceptance Testing.

## 10. Deployment

Antigravity generated application deployed to production.

## 11. Future Enhancements

WhatsApp, Inventory, Mobile App, Cloud Backup.
